PROTECTION-SYSTEM MODERNIZATION

EPICS-Based Area Radiation Monitor Modernization

Updating detector support and data transport for radiation monitoring associated with the Personnel Protection System.

SystemArea Radiation Monitors
IntegrationEPICS
ContextPersonnel Protection

Project Scope

I updated EPICS device-driver support for new Area Radiation Monitor hardware and contributed to modernization of the network path used to transport monitor data.

Engineering Priorities

Because the monitors participate in a protection-system context, the work emphasized reliable data transport, deterministic state visibility, supportable hardware interfaces, and careful separation between monitoring software and independent protection functions.

Impact

The combined hardware, driver, and configuration changes improved maintainability and provided a more scalable foundation for radiation-monitor integration.
