TIMING MODERNIZATION

AI-Assisted Accelerator Timing System

Moving critical timing controls from aging VME/RTEMS infrastructure to maintainable Ethernet-based EPICS services.

Legacy3100 CPU / VME / RTEMS
TargetEthernet EPICS IOCs
HardwareMRF230 series

The Modernization

I led and contributed to development of Ethernet-based EPICS IOCs intended to replace deprecated 3100 CPUs and RTEMS-dependent timing infrastructure. The architecture improved remote diagnostics, software maintainability, and deployment flexibility while reducing reliance on aging VME hardware.

Driver Development

The work included new device-driver support for MRF230-series timing modules. AI-assisted coding accelerated investigation and implementation, while engineering review, build testing, interface validation, and controls-domain judgment remained part of the development process.

Outcome

The project established a more scalable and serviceable direction for accelerator timing, with clearer network access and a reduced dependency on obsolete computing platforms.
